Post to Facebook & Instagram

Compose once and publish to your connected Facebook Page and Instagram Business account using Meta's official Graph API.

Before this works, you need Meta credentials. There's no way for any tool — this one included — to post to your accounts without them; Meta requires it. One-time setup:
  1. Make sure your Instagram account is a Business/Creator account linked to your Facebook Page.
  2. Create an app at developers.facebook.com (Meta for Developers), add the "Facebook Login for Business" / Graph API product.
  3. Using the app's Graph API Explorer, generate a User Access Token with these permissions: pages_show_list, pages_manage_posts, pages_read_engagement, instagram_basic, instagram_content_publish.
  4. Exchange it for a long-lived Page Access Token (Graph API Explorer → select your Page → "Get Token" → Page Access Token; then use the "Access Token Debugger" to extend it to ~60 days).
  5. Look up your Page ID and Instagram Business Account ID (Graph API Explorer: GET /me/accounts, then GET /{page-id}?fields=instagram_business_account).
While your account is in "Development Mode" on the Meta app, only accounts with a role on the app (admins/editors) can post — for public/production use, Meta requires an App Review of these permissions.
